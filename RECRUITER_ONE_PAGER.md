# Recruiter One-Pager — Manufacturing Intelligence Platform

**Candidate:** Aarón Expósito  
**Positioning:** Engineering + Industrial Analytics + Automation

## 30-second summary

I built an end-to-end manufacturing analytics product around a deterministic synthetic factory. It connects production, OEE, quality, downtime and cost data in a small analytical warehouse, then turns those records into executive KPIs, root-cause-oriented insights and quantified improvement scenarios.

## Stack

**Python · pandas · SQL · SQLite · Streamlit · Plotly · pytest · GitHub Actions**

## What to inspect

1. Executive scorecard with comparable-period deltas.
2. Machine OEE vs asset target and health classification.
3. Quantified constraint-recovery opportunity.
4. Defect and downtime Pareto analyses.
5. Scenario Lab for A/P/Q improvement sizing.
6. Data Explorer for row-level auditability.
7. Tests and CI for data reconciliation and KPI correctness.

## Why it matters

The project is intended to show that I can do more than visualise data: I can structure an industrial problem, define metrics correctly, trace them back to source data, communicate the operational implication and connect an improvement action to economic impact.

**All data is synthetic. No confidential employer or customer data is used.**
