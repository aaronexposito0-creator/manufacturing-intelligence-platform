# Changelog

## 2.0.0 — Portfolio Release

- Rebuilt the synthetic data generator with deterministic operating patterns and realistic economics.
- Added asset-specific OEE targets and plant health classification.
- Added previous-period KPI deltas.
- Replaced absolute executive margin with gross-margin rate and plan attainment.
- Added weekly/daily/monthly output trend control.
- Added constraint-recovery opportunity sizing.
- Upgraded Management Insights to impact / driver / action / opportunity format.
- Added true defect and downtime Pareto analyses.
- Added weighted machine × product scrap heatmap.
- Added Scenario Lab for A/P/Q what-if analysis and annualised sizing.
- Added data validation, reconciliation tests and GitHub Actions CI.
- Added a real `dim_date`, additional SQL views and example analytical SQL.
- Improved Windows startup so dependency installation is skipped after first setup.
- Refined UI hierarchy, health/status cues and responsive styling.
